# Sons de motor

Os arquivos `engine-low.wav`, `engine-mid.wav` e `engine-high.wav` são, respectivamente, adaptações nominais dos arquivos `loop_0.wav`, `loop_2.wav` e `loop_5.wav` do pacote **racing car engine sound loops**.

- Autor: domasx2
- Origem: https://opengameart.org/content/racing-car-engine-sound-loops
- Licença: CC0 1.0 — https://creativecommons.org/publicdomain/zero/1.0/
- Alterações neste projeto: somente renomeação; a altura, a filtragem e a mistura são realizadas em tempo real pelo Web Audio API.

Embora a CC0 não exija atribuição, este arquivo deve ser preservado junto com os áudios para manter a procedência documentada.
